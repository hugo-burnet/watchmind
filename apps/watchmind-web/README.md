# WatchMind Web

Socle React/Vite/TypeScript et laboratoire visuel du lot 15.

```bash
npm install
npm run dev
```

Vite transmet `/api` à `http://127.0.0.1:3000`. Le laboratoire repose sur des
données mockées et fonctionne sans le backend.

Les captures de revue se régénèrent avec `npm run preview`, puis
`npm run capture` dans un second terminal.
